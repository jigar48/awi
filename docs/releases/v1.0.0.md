# Agent Workflow Inspector v1.0.0 — Deterministic AI Agent Trace Diagnostics

Published on [GitHub](https://github.com/jigar48/awi/releases/tag/v1.0.0) October 19, 2026. [npm version 1.0.0](https://registry.npmjs.org/agent-workflow-inspector/1.0.0) confirmed October 20, 2026.

Agent Workflow Inspector is a local-first, deterministic linter for AI agent execution traces. It highlights recorded patterns for investigation; it does not understand agent intentions or prove a workflow is stuck.

## Included in V1

- Six bounded rules covering repeated tool calls, repeated failures, execution cycles, rapid retry attempts, operation/depth limits and associated recorded leaf resource usage.
- Versioned AWI JSON and the [documented OTLP JSON subset](https://github.com/jigar48/awi/blob/v1.0.0/docs/trace-formats.md); no blanket framework compatibility claim.
- CLI and ESM/TypeScript library, configurable thresholds, human-readable and structured JSON reports, stable evidence references and CI exit codes.
- Local analysis without telemetry or an LLM. Input budgets, terminal escaping, symlink checks and exclusive output creation.

## Install

```sh
npm install --global agent-workflow-inspector@1.0.0
awi --help
awi inspect trace.json --format json
```

Requires Node 22.18+ (22.x), 24.11+ (24.x), or 26.x. Exit 0: completed below threshold; 1: invalid input, operational failure or incomplete analysis; 2: completed with findings meeting the configured threshold (high by default).

The audited source passed 69 tests and nine hosted Windows/macOS/Linux × Node 22/24/26 jobs. These historical results do not validate later documentation or verification-script changes; see the [verification record](https://github.com/jigar48/awi/blob/v1.0.0/docs/verification.md).

## Privacy and limitations

Default reports omit raw arguments, results, messages and metadata. Trace/operation identifiers remain visible and can themselves contain sensitive data. Opt-in content display uses limited key-based redaction and can expose secrets. Review reports before sharing.

Intentional polling/retries can trigger findings. Missing timestamps, concurrency, incomplete exports, bounded windows and leaf-only resource attribution limit detection and accounting. Resource estimates do not establish causality or financial waste.
