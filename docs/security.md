# Security and privacy

All trace content is inert untrusted JSON. AWI never obeys embedded instructions. Analysis uses no eval, shell execution, URL fetching, telemetry, network, database or intermediate content files. Fixed limits apply to parsing, files, spans, nesting, strings, traversal, cycles, findings and default report amplification. Shared native values count once per occurrence against the processed-content budget.

Default JSON and human reports generated by AWI use report-local ordinal references such as `trace-1` and `op-1`. The references encode rank in a deterministic order. They contain no raw identifier bytes or hashes and are scoped to one report (`op-N` is scoped to one trace within that report). AWI007 still compares exact tool names and error codes internally. Its report gives the number of failures, number of distinct argument fingerprints, and operation references. Default reports omit raw names, codes, arguments, results, prompts, metadata, error messages and fingerprint values. AWI006 uses `currency-N` keys in place of recorded currency labels and preserves each currency group's amount.

Reports still expose counts, timing, usage, cost amounts, source indices, relative identifier order, and relationships within the workflow. Those details can be sensitive or allow inference when combined with other data. Review them before sharing. These guarantees apply to reports produced by AWI analysis. The public renderers format the report supplied by the caller and can display strings the caller inserts.

`--show-content` and the third argument to `analyze(traces, config, true)` add a separate `content` section with the recorded trace ID and normalized operations, including recorded operation and parent IDs, names, tool names, error codes, and arguments. Recursive redaction of operations replaces values under keys matching authorization, password, secret, token, API key, cookie, credential, prompt, message, output or result. Arbitrary strings and keys can still reveal private data. Keep these reports private. AWI never transmits trace content.

JSON serialization escapes control and formatting characters where needed. Human output replaces terminal controls, bidirectional formatting and line/paragraph separators. Severity color is limited to supported interactive terminals and honors `NO_COLOR` and `--no-color`.

Parsing rejects `__proto__`, `constructor` and `prototype` object keys. No prototype merging occurs. Files are size-checked before parsing, decoded as strict UTF-8 (optional BOM accepted), and read in bounded chunks even if they grow. Aggregate limits count bytes actually read. CLI rejects symlink entries and symlink components of trace/configuration/output paths. Resolve legitimate OS aliases (including macOS /var temporary paths) to real paths first. POSIX opens also use O_NOFOLLOW, and all platforms compare the opened file identity with the checked file. This is not a filesystem sandbox against concurrent replacement of directory components: use trusted directories and OS permissions. Reports use an adjacent temporary file with mode 0600 on POSIX (Windows uses inherited filesystem ACLs), fsync and atomic exclusive hard-link publication. Existing targets are never overwritten. Cleanup is attempted on ordinary failures; OS errors can prevent removal. Filesystems without hard links fail closed. Crashes or cleanup failures may leave .tmp files to inspect/remove locally under the same filesystem permissions.

Broken stdout pipes produce a controlled operational failure, without an uncaught stack trace. Errors omit raw parser content, OS filenames and stacks. Schema errors show field paths/codes. See [the security policy](../SECURITY.md) for private disclosure guidance.
